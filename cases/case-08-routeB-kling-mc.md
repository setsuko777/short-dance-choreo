## 1. 路线 B 的本质差异（先读这个）

路线 B **不产出了多镜分镜表**——可灵 MC 是「角色图 + 动作视频 → 逐帧复刻」的单主体、无切、无运镜生成。本流水线的多镜特写宪法（5 处锚点落镜头 2–6、切点吸附）在 MC 模式下**不适用**，替代约束是：

| 多镜宪法 | 路线 B 替代规则 |
|---|---|
| 切点吸附 downbeat | 动作视频自带的节奏（MC 逐帧复刻，天然卡点） |
| 5 处特写锚点 | 由参考视频内容决定——**选段时就按锚点选**（见 §3 覆盖矩阵） |
| 镜头纪律（角度序列等） | 单镜无角度序列问题；景别匹配替代（全身参考→全身角色图） |
| 负面词防崩坏 | MC 面部绑定说明 + 参考视频质量 |

## 2. 输入规格（用户需备齐）

| 槽位 | 职责 | 规格 |
|---|---|---|
| 角色图 ×1 | identity | 正面全身；**景别必须匹配动作视频**（全身参考→全身角色图）；短边 ≥340px、长边 ≤3850px |
| 动作参考视频 ×1 | motion | Match Video 3–30s（或 Match Image ≤10s）；单主体、无切、无运镜；画面干净 |
| 面部元素 ×1–4 | identity-面部 | Match Video 模式：1 正面 + ≤3 角度（V3 面部绑定） |
| 原声 | audio | MC **保留参考视频原声**，不生成新音频——发布时音乐授权 = 参考视频音乐的授权，须单独确认 |

## 3. 参考视频选段覆盖矩阵（按锚点选段）

用户说「复刻某支热门舞蹈」时，按目标锚点选参考视频段落；本流水线不拆解受版权保护的整段编舞（版权红线），选段即授权确认对象：

| 优先级 | 目标锚点 | 参考视频选段要求 | 说明 |
|---|---|---|---|
| P0 | ③胸/腰（爆点） | 含明显手臂展开 + 胸腔展开动作的 2–4s | 爆点复刻是路线 B 的核心价值 |
| P0 | ⑤小腿 | 含清晰脚步语汇的 2–4s | 与 ③ 拼接成最短可复刻单元 |
| P1 | ①眼 | 含眼神指向镜头/面部特写的 1–2s | 依赖 MC 面部绑定质量 |
| P1 | ②嘴 | 含口型开合的 1–2s | 同上 |
| P2 | ④大腿 | 含腿部动作的 2s | 景别需含大腿至脚 |

## 4. 提示词结构（R5 模板）

MC 模式提示词 = **角色描述 + 复刻指令 + 保留项**，不写动作细节（动作来自参考视频，写细节反而干扰复刻）：

> 画面中的【角色外观描述：发型/服装/配色，与角色图严格一致】完整复刻参考视频中的舞蹈动作，保持每个动作的节奏与力度一致，面部表情自然，身体比例稳定，服装外观全程不变。9:16 竖屏构图，人物全身入画，头顶与鞋底留安全区。背景为【纯色背景描述】。保留参考视频的原始声音。

槽位表（MC）：identity = 角色图 + 面部元素；motion = 参考视频；audio = 参考视频原声（保留）。**不分配 style/environment 槽**（MC 不接这两类参考，背景由角色图与提示词锁定）。

## 5. 负面提示词

基础集（12 项）+ MC 追加：面部绑定说明（Match Video 模式挂面部元素；防面部崩坏与身份漂移）。
