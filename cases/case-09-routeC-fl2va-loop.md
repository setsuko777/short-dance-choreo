## 1. 路线 C 的本质：循环 = 首尾同姿态

无缝循环的充要条件：**尾帧姿态 = 首帧姿态**。FL2VA 的 0/1/2 图槽位中：

| 槽位 | 内容 | 规格 |
|---|---|---|
| `opening`（首帧图） | 起手姿态 + 背景 | **背景锁定来源**；姿态选「可长时间保持的静止姿」（如双手轻拢、比心定格） |
| `ending`（尾帧图） | 收姿 = **首帧同姿态** | 与首帧图**同一张图或同姿态重绘**（推荐同一张，漂移为零） |
| `identity`（可选） | 角色图 | 外观一致性 |

**音乐假设**：循环视频的节拍假设 120 BPM 整点（6s = 3 bar 整网格，切点 0/2/4/6s）——这是「=120.0 整点窄带」少数的**主动应用场景**（假设值无违宪风险，因为本来就是设计值而非测量值）。

## 2. 动作设计（R3，循环向）

6s 循环的动作经济学：起手（静止）→ 展开 → 高潮 → 收回 → 静止（= 起手）。全部动作必须**回到起点**，不引入新姿态。

| 时间 | 功能 | 动作（引用 L3-O01 语汇） | 说明 |
|---|---|---|---|
| 0–2s | 起手（静止） | 双手胸前比心定格 | 首帧姿态；静 2s 是循环的「呼吸口」 |
| 2–4s | 展开 | 比心递向镜头 + 眼神弯起（L3-O01 拍2–4） | 循环的「内容段」 |
| 4–5.5s | 高潮 | 双手缓慢收回胸前（L3-O01 拍5） | 渐缓 |
| 5.5–6s | 收姿（静止） | 比心定格 = 首帧 | 尾帧姿态 |

**无特写锚点声明**：路线 C 单镜生成，多镜特写宪法不适用；动作按「可特写化」标准设计（①眼在 2–4s 段可见），但**不宣称 5 处锚点**。
