# R2 风格考据员 — Style Library 规范

> 版本：v1.0（2026-10-24）· 对应 SKILL.md Phase 2 · 两段式：第一段与 R1 并行，第二段等 R1 卡点表落地

## 职责

把用户的模糊风格需求（「燃」「甜」「国风」）转成可执行的**舞种 + 能量等级 + 场景服装包**，并绑定动作语汇、BPM 适配区间与崩坏风险点。

## 两段式流程

**第一段（与 R1 并行）**：舞种候选从下方 D1 标签库选取；每个候选绑定：动作语汇（arm lines / footwork / grooves）、适配 BPM 区间、适配服装、风险点。若用户已指定舞种 → 跳过候选直接进入风险点评估。

**第二段（R1 落地后）**：按卡点密度与 drop 位置定能量等级 L1–L5；套平台微调规则；输出「舞种 + 能量 + 场景包」定档结论。

## D1 舞种标签库（种子：AIST++ 十舞种 + 二次元/国风增量类）

| 舞种 | 适配 BPM | 动作语汇 | 服装 | 风险点 / 降级规则 |
|---|---|---|---|---|
| K-pop | 110–140 | 大幅 arm lines、point 舞、队形变换 | 舞台服 / 街装 | 高速手部崩坏 → 手速上限「1 拍 1 动作」 |
| Hip-hop（Middle/LA-style） | 85–120 | grooves、bounce、wave | 宽松街装 | 地面动作高危 → 只取站姿语汇 |
| 宅舞 / 二次元 | 110–140 | 手势舞、wotagei、轻跳跃 | 洛丽塔 / 舞台服 | 跳跃离地 → 单镜 ≤1 次小跳 |
| 国风 | 70–110 | 水袖、身韵、圆场步 | 国风服（垂坠感） | 长袖遮挡 → 特写镜避开袖摆峰值 |
| Jazz / urban choreography | 100–130 | isolation、walk、layering | 舞台服 | 大幅旋转 → 降级轻缓转身 |
| Breaking | 90–130 | toprock / footwork | 宽松街装 | **地面动作崩坏率极高 → 默认只取 toprock** |
| 社交潮流舞 | 95–125 | 简单重复、跟跳友好 | 日常装 | 动作过简 → 特写锚点需人工补 |
| Latin | 100–140 | 髋部律动、快速移步 | 垂坠感裙装 | 移步滑步 → QA 查脚步滑动 |
| 慢板律动（R&B） | 70–95 | 慢 wave、身型控制 | 休闲 / 裙装 | 特写密度低 → 拉长单镜保特写 |

标签定义与 D2–D6 的完整六维体系见 `datasets/taxonomy.md`；本文件只管 R2 的选型逻辑。

## D2 能量等级（L1–L5）

| 等级 | 卡点密度 | 单镜时长 | 主动作数 | 切分节奏 |
|---|---|---|---|---|
| L1 慢板律动 | 每 4–8 拍 | 3–3.5s | ≤2 | 疏 |
| L2 中速 | 每 4 拍 | 2.5–3s | ≤3 | 中 |
| L3 中快 | 每 2–4 拍 | 2–2.5s | ≤3 | 较密 |
| L4 高速卡点 | 每 1–2 拍 | 2s | ≤3 | 密 |
| L5 drop 爆发 | 重拍驱动 | 2s | ≤3 | 只落在 drop 段 |

定档规则：R1 卡点密度（每拍视觉变化期望）+ drop 位置决定 L 值；抖音默认 L3–L4，小红书 L2–L3，B站可 L2。

## 平台微调规则表

| 平台 | 优先 | drop 位置 | 特写策略 | 循环 |
|---|---|---|---|---|
| 抖音 | 卡点优先 | 前置（15–40%） | 爆点特写早出 | 不要求 |
| 小红书 | 循环优先 + 姿态美 | 中置（40–55%） | 特写与姿态镜交替 | 末帧 = 首帧姿态 |
| B站 | 稍长叙事可接受 | 标准（40–60%） | 5 处全上 | 不要求 |

## 输出（定档结论）

```
舞种：K-pop ｜ 能量：L4 ｜ 假设/实测 BPM：128（实测）
场景包：室内自然光 / 舞台服 ｜ 平台微调：抖音-卡点优先，drop 前置
风险点：高速手部（限 1 拍 1 动作）；无地面动作
```

## 与其他角色的接口

- → R3：舞种语汇 + 能量等级（决定舞句选取与密度）
- → R4：能量等级（决定切分节奏与机位）
- QA 回退映射：风格能量错档 → 回退本角色
