# R1 节奏分析师 — Beat Analysis 规范

> 版本：v1.0（2026-10-24）· 对应 SKILL.md Phase 1 · 工具：`scripts/beat_tracker.py`（numpy 零依赖，M0 已验证）

## 职责

音乐解码 → BPM / 段落结构 / downbeat 序列（毫秒级）→ **卡点表 + 切点吸附锚点**。Phase 4 的所有镜头边界只能从本角色输出的 downbeat 集合中选取。

## 工具链（拍板：numpy 零依赖保底 + librosa 可选增强）

**默认路线（不依赖 librosa）**：
1. `ffmpeg -i in.mp3 -ac 1 -ar 22050 -f f32le out.raw` 解码为单声道 PCM（static_ffmpeg 经 `_find_ffmpeg` 三级定位自动解析，PATH 注入非必需）
2. 分块 STFT → 对数频谱通量 onset 包络
3. ACF + 梳状加权 + 高斯先验（中心 120 / σ45）测速，取 60–200 BPM 主峰
4. DP 节拍跟踪（0.75–1.3× 周期转移 + 强网格惩罚）→ downbeat 序列
5. 4/4 downbeat 相位选择 → 能量三分位 regime 段落量化

**可选增强**：librosa 1.0.0（已实装，py3.13.14 验证 import 正常；numba 0.68 / scipy 1.18 / soundfile 0.14 均有 cp313 wheel）。用于交叉验证或扩展功能；默认路线不依赖，librosa 不可用不 block。

**CLI**：
```bash
python scripts/beat_tracker.py -i music.mp3 -o beats.json
```

## 产出格式

```json
{
  "bpm": 120.25, "bpm_confidence": 0.87, "bpm_alternatives": [{"bpm":156,"score":0.71}],
  "beats_ms": [0, 499, 998, ...], "downbeats_ms": [0, 1996, 3992, ...],
  "sections": [{"label":"intro","start_s":0.0,"end_s":27.8}, {"label":"drop",...}],
  "drop_s": 27.8, "alignment_error_ms": 2.8
}
```

人读摘要格式：`[00:00.0-00:02.0] intro / BPM=128 / downbeats: 0.0, 1.88, 3.75, 5.63...（bar=1.875s）/ drop@00:06.0 / 对齐误差 ±3ms`

**必填字段纪律**：`bpm_alternatives` 必须暴露 top-3 速度候选（含分数）——速度歧义（如 104 vs 156）不私自裁定，交人工抽检。

## 吸附锚点规则（宪法 6 的执行细则）

**总原则**：切点必须落在 R1 实测节拍网格上（±80ms 容差 = 2×24fps 帧长），禁止自由切；镜数**不固定**，由网格枚举器按 BPM 算出。

**吸附单位三级优先**（M3 校准结论，`scripts/shot_grid.py` 实现，单测见 `tests/test_shot_grid.py`）：

1. **bar 吸附**（首选）：每镜 1 bar（慢板可 2 bar），末镜截短至模板终点（≥2.0s）。BPM 88–120 区间大部分可行；96/120 为整数网格
2. **拍吸附**（快板兜底）：当 1 bar < 2.0s 或 15s 铺不满时（约 106–144 BPM），每镜 4–8 拍（整数拍），切点落拍。产出须标注「拍吸附模式」
3. **2-bar 吸附**（极快板）：BPM ≥ 148 时 2 bar ≤ 3.5s，回到整数 bar 单位

**执行方式**：Phase 4 先跑 `python scripts/shot_grid.py 15 <bpm>` 拿推荐网格，再填分镜表；无解时脚本如实报错（exit 2），**禁止手捏违宪切点**——改换模板时长或报 QA。

**常用 BPM 网格速查**（由 shot_grid.py 实测枚举生成；镜数为典型值，切点毫秒数以脚本输出为准）：

| BPM | 15s 完整版 | 6s 精简版 |
|---|---|---|
| 88–92 | 拍吸附 5 镜 | bar 2 镜 |
| 95–104 | bar 6 镜 | bar/拍 2 镜 |
| 108 | 拍吸附 6 镜 | 拍 2 镜 |
| 112–120 | bar 7 镜 | bar 2–3 镜（仅 ≈120 可 3 镜） |
| 124–140 | 拍吸附 6 镜 | 拍 2 镜 |
| 148–160 | bar 5 镜（2-bar 单位） | bar 2 镜 |
| 174–180 | 拍吸附 6 镜 | bar 2 镜 |

**其他细则**：
- 段落功能顺序固定（起手→眼→嘴→drop 胸腰→大腿→小腿+定格），**绝对时间全部由卡点表算出**——drop 实测在 40% 就落 40%，禁止按 50% 模板硬搬
- drop 段（chorus/drop regime）必须预留 ≥1 个特写锚点；若实测段落过短（<4s）→ 向 QA 报备并在分镜表标注
- 15s 完整版典型镜数 5–7、6s 精简版 2–3 镜（6s 版 3 镜仅在 **BPM = 120.0±0.1** 成立——M4 实测 120.25 差 3.3ms 即违宪；6s 版默认形态是 2 镜）

## 窗口选择规则（M4 新增）

用户给的音乐通常 30s–4min，成片只取其中一段。窗口选择直接决定能量曲线，规则：

1. **15s 完整版**：窗口起点 ≈ 全曲实测 drop − 7s（使 drop 落窗内 40–55%）；若 drop < 8s（前段就有 drop）则窗口起点 = 0
2. **6s 精简版**：窗口起点 ≈ drop − 2s（drop 落窗内 33–36%，③爆点镜 2 完整覆盖）
3. 窗口起点优先取**全曲 downbeat**（起手落在小节线上）；取不到时取最近的拍
4. **裁切必须样本级精确**：用 `scripts/trim_window.py`（全解码→切片→编码）。剪映曲库 m4a 用 ffmpeg `-ss` seek 有约 20s 偏差（M4 实测），直接用 seek 会裁错段落
5. 裁切后**重跑 beat_tracker** 得窗内 BPM/drop/段落——窗内分布与全曲不同（90 分位参考值变化），drop 位置以窗内实测为准

## 段落 → 能量曲线映射

| 段落 | 位置（启发式） | 能量 | 编排含义 |
|---|---|---|---|
| intro | 0–15% | 低 | 蓄力，起手 hook 落此 |
| verse | 15–40% | 中 | 展开，特写①② |
| chorus/drop | 40–75% | 高 | 爆发，爆点特写③ |
| outro | 75–100% | 收 | 定格收尾（可循环姿态） |

drop 判定 = 能量与新异度双高点；无低→高跃变的全程高能曲（如 30s 快闪）走 onset 密度兜底（15% 后最大密度点）——**兜底值必须在产出中标注「drop 为兜底估计，需人工确认」**。

## 已知限制（如实记录，不美化）

1. 段落标签是启发式的，细粒度 verse/chorus 允许人工修正（人工修正记录进 changelog）
2. 速度歧义（半速/倍速）由 `bpm_alternatives` 暴露，最终裁定权在人工抽检
3. 检测器群延迟约 -28ms 已做常数补偿（M0 合成轨校准）；换解码参数需重新校准
4. 用户只给文字感觉词时：按感觉→BPM 区间模板假设（见下表），产出标注「节拍为假设值，建议替换实测」
5. **短窗（<30s）downbeat 相位不稳定**（M4 实测：15s 窗内相位与全曲分析可差约 3 拍）——窗内切点优先用拍吸附（相位无关）；downbeat 序列仅作参考
6. **6s 版 3 镜网格是 =120.0 整点窄带**（±0.1 BPM）；实测 120.25 即不可用，默认 2 镜
7. **慢板区（88–94 BPM）15s bar 吸附无解**（15s 铺不满整数 bar）；拍吸附是唯一合宪模式，5 镜 → ①+hook 合并（见 `move-library.md`）
8. **假设节拍在 15s 尺度不可用**：M1→M4 基线对比实测，0.5 BPM 假设误差累积 160ms（切点 2–5 全超 ±80ms 容差）——纯文字路径的产出必须带「建议替换实测」声明，用户补音频后重算而非微调

| 感觉词 | 假设 BPM | 段落模板 |
|---|---|---|
| 燃 / 炸 / 卡点 | 128–140 | intro 8% → drop 前置 35% |
| 甜 / 可爱 / 宅舞 | 110–125 | intro 12% → drop 50% |
| 酷 / 帅 / hip-hop | 90–105 | intro 15% → drop 55% |
| 慢 / 慵懒 / R&B | 70–85 | 无明显 drop，双 verse 结构 |

## 与其他角色的接口

- → R2：卡点表（定能量等级与段落映射）
- → R3：downbeat 集合（舞句排布的拍网格）
- → R4：吸附锚点（切点唯一来源）
- QA 回退映射：节奏不符 / 切点未吸附 → 回退本角色
