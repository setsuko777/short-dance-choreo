# R6 质检员 — QA Checklist 规范

> 版本：v1.0（2026-10-24）· 对应 SKILL.md Phase 6 · 一票打回权 · 六查全过才放行

## 职责

对 R5 产出的提示词 + 分镜表执行**六查**，每项 pass/fail + 原因。任一项 fail → 按责任角色映射回退；最大深度 2 层，超限升级人工裁决。回退计数写入 changelog。

## 六查清单

### 查 1 — 特写覆盖
- [ ] 5 处特写（眼/嘴/胸/大腿/小腿）全部存在且分布在镜头 2–6
- [ ] 每处锚点**双侧明确**：R3 动作侧（可特写化动作）+ R4 镜头侧（景别机位落到特写）
- [ ] 爆点特写③落在 R1 实测 drop 段内
- [ ] 6s 版：按降级规则保 3 处（眼/胸腰/小腿）并标注「非完整版」
- [ ] **景别复核子项（生成层，DG-015）**：分镜表标注「特写/中景」的镜头，生成结果必须实际核验景别——全身参考图 + 纯 Ref2VA 时 H3 会忽略文字推近指令；凡推近镜必须有首帧构图锚点图（`first_frame` 槽位）或更强的运镜描述，否则该镜降级为「广角 + 身体锚点」并登记
- fail 归因：特写缺失 / 景别不符 → R4；锚点动作不可特写 → R3

### 查 2 — 镜头语言
- [ ] 水平平视为默认视角，特写/竖构图占比合理
- [ ] 无连续两次相同角度
- [ ] 俯仰镜头（含低角度仰拍）整条 ≤2 次
- [ ] 机位未越权：环绕仅 drop 段且 ≤1 次且有 QA 特批记录
- [ ] **切点吸附**：每个镜头边界落在 R1 节拍网格 ±80ms 内；吸附单位合规（bar 优先；拍吸附模式已标注「拍吸附模式」；2-bar 仅用于 ≥148BPM）；镜数与 `shot_grid.py` 枚举结果一致，无手捏切点
- [ ] 单镜时长全部在 2.0–3.5s
- fail 归因：切点来源错（网格算错）→ R1；切点选取错（来源对但填错）→ R4

### 查 3 — 动作密度
- [ ] 单镜主动作 ≤3
- [ ] 相邻镜动作类型错开（手部→腰部→腿部→全身）
- [ ] 高危动作扫描：大幅旋转 / 地面动作 / 快速手部 / 连续跳跃，命中即查降级记录
- fail 归因：→ R3

### 查 4 — 崩坏风险
- [ ] 背面图存在性：背身/转身镜头有背面图依据（无则镜头已删）
- [ ] 首尾帧姿态可拼接（末镜定格 = 首镜起手）
- [ ] 每镜通过条件可观察、可判定（无主观词）
- [ ] 初稿是否先用定点广角暴露崩坏再叠加运镜（借 #22）
- fail 归因：姿态不可拼接 / 广角未验 → R4；高危动作未降级 → R3

### 查 5 — 一致性
- [ ] 负面词基础集 12 项完整，含 `no extra fingers` 与背景锁定项
- [ ] 模型追加集按目标模型齐全（H3 中文锁定句 / MC 面部绑定 / Seedance no shot change / Vidu no third person）
- [ ] 背景锁定句在位且与首帧背景描述一致
- [ ] 槽位分配无职责冲突（一个参考一个职责）
- fail 归因：→ R5

### 查 6 — 发布合规（强制，不可跳过）
- [ ] AI 显式标识提醒已写入发布检查单（平台「AI 生成」声明开关）
- [ ] AI 隐式标识：未提供任何去除元数据 AIGC 标识的指引
- [ ] 音乐来源：平台授权曲库或有授权记录
- [ ] 无敏感内容；知名编舞整段照扒已标注
- fail 归因：合规缺项 → R6 自己补发布检查单，不放行

## 生成层回流核验（M5 起，视频产出后执行）

1. **逐镜抽帧**：每镜取首/中/尾 3 帧核验——锚点动作是否发生、角色是否一致、背景是否锁定。**抽帧必须用输出 seek（`-i` 在前 `-ss` 在后）或全帧扫描**；输入 seek 落非关键帧会产生边缘伪影误报（CASE-01 v1 实证，DG-016）
2. **全帧伪影扫描**：对成片逐帧做边缘暗列检测（黑边/裁切伪影），CASE-01 v1 的 361 帧全扫描 0 伪影
3. **景别核验**：对照分镜表景别列逐镜核对（DG-015 子项）
4. **回流落点**：结果写案例「回流记录」段；命中降权条件的登记 `degradation-log.md`；cases/README 索引状态同步更新

## 责任角色映射（打回路由表）

| 症状 | 回退到 |
|---|---|
| 特写缺失 / 景别不符 | R4 |
| 动作超密度 / 锚点不可特写 | R3 |
| 节奏不符 / 切点未吸附（切点来源错） | R1 |
| 切点未吸附（选取错，来源对） | R4 |
| 风格能量错档 | R2 |
| 提示词格式 / 负面词缺失 / 槽位冲突 | R5 |
| 合规缺项 | R6 自己补，不放行 |

回退深度 ≤2 层；超限或同一症状回退 ≥2 次 → 升级人工裁决，记录原因。

## 废片原因字典（受控词表，R7 归档用）

`drift 漂移` · `limb 肢体崩坏` · `clipping 穿模` · `rhythm 节奏不符` · `framing 构图失败` · `face 面部失真` · `compliance 合规缺项` · `other`

每条 QA 结论格式：`六查逐项 pass/fail + fail 原因（受控词表）+ 回退路由 + 放行/打回`。

## 与其他角色的接口

- ← R5（提示词 + 槽位分配表）+ R4（分镜表）
- → R7（QA 结论回流归档）
- 高危模式累计 ≥3 例 → 通知 R7 对 move-library 对应舞句自动降权
