# R3 编舞师 — Move Library 规范

> 版本：v1.0（2026-10-24）· 对应 SKILL.md Phase 3 · 舞句库随 M2/M3 数据集建设填充，本文件先定规则与首批种子

## 职责

把舞种语汇按 R1 拍网格排成**动作编排表**：每拍含主动作、可特写化锚点、通过条件。控制动作密度，保证 5 处特写的「动作侧」成立。

## 基本单元：舞句 = 8 拍

| BPM | 8 拍时长 |
|---|---|
| 96 | 5.0s |
| 120 | 4.0s |
| 128 | 3.75s |
| 140 | 3.43s |

一条舞句 = 8 拍内的动作序列，逐拍标注：`主动作 / 身体部位 / 可特写化(Y/N) / 锚点类型 / 通过条件`。

## 功能骨架（只定顺序，不定绝对时间）

```
起手 hook → 特写①眼 → 特写②嘴 → drop 爆点特写③胸/腰 → 特写④大腿 → 特写⑤小腿 + 收尾定格
```

- 15s 完整版：典型 5–7 镜（由 `shot_grid.py` 按 BPM 枚举，96BPM=6 镜、112–120BPM=7 镜、128BPM=拍吸附 6 镜）；特写①②在 verse、③在 drop 段、④⑤在 outro 前
- **15s 版镜数 <6 时**（如慢板 88BPM = 5 镜）：启用「①+hook 合并进首镜」（与 6s 降级同款），②③④⑤ 落镜头 2–5，**5 处锚点全保留不删**
- 6s 精简版：首镜「起手 hook + 特写①眼」合并（近景起手，第 1 拍眼神随动作指向镜头）→ 爆点特写③胸/腰 → 特写⑤小腿 + 定格；保 3 处（眼/胸腰/小腿），标注「非完整版」。镜数按网格：**BPM = 120.0±0.1 时 3 镜 × 2.0s（bar 整网格，窄带例外）；其余 BPM 枚举通常为 2 镜**——2 镜版保 2 处锚点（①+hook / ③），②④舍弃、⑤降为收尾动作，单镜放宽到 2.5–3.5s
- 每镜时长 = 相邻吸附节拍之差（bar 优先、拍兜底；2.0–3.5s）；**drop 位置以 R1 实测为准，禁止把 drop 特写移出 drop 段**

## 锚点归属（已澄清，QA 双侧分查的依据）

- **R3 负责动作侧**：定义「可特写化的动作」——该动作在执行时，对应身体部位必须处于可被特写清晰捕捉的状态
  - 眼部 anchor = 眼神指向镜头 + 手部上抬（不挡脸）
  - 嘴部 anchor = 口型/表情变化 + 头部微侧
  - 胸腰 anchor = 胸腔展开 / 腰部 isolation + 大幅度手臂动作
  - 大腿 anchor = 腿部伸展或跨步 + 裙摆/裤脚不遮挡
  - 小腿 anchor = 脚跟离地 / 点步 + 全身或小腿入画
- **R4 负责镜头侧**：保证该镜景别与机位能落到特写（见 `camera-language.md`）
- 一个锚点必须动作侧 + 镜头侧同时成立才计数；QA 缺任一侧即打回对应角色

## 编排规则

1. 单镜内主动作 ≤3 个（手机小屏一眼读懂）
2. 相邻镜头动作类型错开：手部 → 腰部 → 腿部 → 全身
3. 高危动作清单（默认降级）：大幅旋转 → 轻缓转身；地面动作 → 站立语汇；快速手部 → 1 拍 1 动作；连续跳跃 → 单镜 ≤1 次小跳
4. 动作必须适配 R2 定的能量等级（L4/L5 才允许重拍驱动密集切）
5. 收尾定格姿态 = 首帧起手姿态（循环友好；路线 C 时尾帧由用户给定）

## 每拍通过条件（可观察验收标准，示例）

| 部位 | 通过条件示例 |
|---|---|
| 通用 | 全身及脚部接触地面始终可见；方向与肢体数量保持稳定 |
| 眼部特写 | 面部与服饰仍清晰可辨；无手部遮挡 |
| 胸腰特写 | 躯干无扭曲穿模；手臂不过肩线 |
| 大腿特写 | 双腿无额外肢体；裙摆/裤脚形态稳定 |
| 小腿特写 | 双脚滑动位移 ≤1 个脚掌宽；双脚不穿出画框 |

> 通过条件写法纪律：**可观察、可判定、不含「感觉良好」类主观词**。借 seedance.tv 节拍表方法论。

## 舞句库状态与降权记录

- M1 当前：库为空，规则先行；M3 目标 50 个 8 拍舞句（≥6 舞种，每舞种 ≥L2/L4 各 3 条，每条带锚点 + 路线 A/B/C 适配标注）
- **自动降权闭环**（R7 执行）：同废片原因累计 ≥3 例的舞句 → 标「高危」→ 本库降权或下架，复用需 QA 特批
- 降权记录格式：`舞句ID / 废片原因 / 累计例数 / 降权日期 / 解禁条件`

## 与其他角色的接口

- ← R1（拍网格）、R2（舞种 + 能量）
- → R4（动作编排表 + 锚点定义）
- QA 回退映射：动作超密度 / 锚点不可特写 → 回退本角色
