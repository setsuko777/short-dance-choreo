# R4 镜头导演 — Camera Language 规范

> 版本：v1.0（2026-10-24）· 对应 SKILL.md Phase 4 · 机位库与 D4 标签一一对应

## 职责

把 R3 的动作编排表转成**分镜表**：切分（吸附 downbeat）、机位/景别/角度分配（保证锚点镜头落到特写）、转场设计。输出含通过条件列的镜头表，交 R5 出稿。

## 镜头表字段（10 列，缺一不可）

| 镜号 | 时间区间（吸附 downbeat） | 时长 | 机位 | 运动 | 景别 | 角度 | 主动作 | 特写锚点 | 转场出/入 | 通过条件 |

> 表头 11 项（镜号 + 10 列）。分镜表示例见 `examples/output/`。

## 切分纪律

1. 切点只能取 R1 的 `downbeats_ms` 集合，容差 ±80ms
2. 单镜 2–3.5s；单次生成总时长 ≤ 目标模型上限（引用 `model-matrix.md`）
3. 15s 版 6 镜 / 6s 版 3 镜；只有一张角色图 → 降 3–4 镜

## 机位库（与 D4 标签一一对应）

| 机位 | 用途 | 风险 |
|---|---|---|
| 定点 | 默认；特写锚点主力 | 单调（靠动作变化补） |
| 缓慢推近 | 蓄力段、drop 前置 | 推近中特写漂移 |
| 缓慢横移 | 过渡镜、展示全身 | 小屏肢体变形 |
| 手持微晃 | 街头/现场感 | 与背景锁定冲突时禁用 |
| ~~环绕~~ | **高危变体**：仅 drop 段、≤1 次、QA 特批 | 切出画 / 穿模高危 |
| 低角度仰拍 | 计入俯仰次数 | 同俯仰纪律 |

## 角度纪律

- **水平平视为默认视角**；角度序列按「四分之三侧 → 纯侧 → 过肩 → 背身 → 回正面」排布
- **禁止连续两次相同角度**
- 俯仰镜头（含低角度仰拍）整条 ≤2 次
- 背身镜头：角色图无背面图时**禁止排**（Phase 0 硬规则）；只有一张图时删转身镜头

## 景别与特写落位

- 特写锚点落位镜头 2–6（15s 版）；6s 版按降级规则保 3 处
- 景别序列：全身/中景铺陈 → 近景/特写爆点 → 回中近景收（避免全特写疲劳）
- 爆点特写③必须落在 drop 段（R1 实测）
- 末镜定格姿态 = 首镜起手姿态（循环拼接）

## 转场设计

- **动作遮罩转场优先**：甩手 / 转身 / 蹲起遮挡画面切换，其次硬切
- 连续性准则（借 OneTake）：每个镜头边界「有物体存活并变成下一拍」——转场出/入列必填
- 末镜定格须与首镜起手姿态可拼接（QA 第四查会验）

## 通过条件列（每镜必填）

从 R3 的每拍通过条件中选取该镜适用的条目；特写镜必须含部位专属条件（见 `move-library.md` 通过条件表）。**先固定广角暴露脚步滑动/手部消失/关节畸变，再谈运镜**（借 seedance.tv 方法论）——即分镜初稿先用定点广角验崩坏，再叠加运动。

## 与其他角色的接口

- ← R1（吸附锚点）、R2（能量等级）、R3（动作编排表 + 锚点）
- → R5（分镜表）
- QA 回退映射：特写缺失 / 景别不符 / 切点未吸附执行错误 → 回退本角色（切点来源错误退 R1）
