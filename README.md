# 短视频舞蹈编排 Short-Dance-Choreo

把「角色图（支持四视图）+ 音乐」变成符合短视频平台节奏的 **9:16 舞蹈视频提示词**，支持文本驱动 / 动作迁移 / 首尾帧锁定三条生成路线，以及**逐镜拼接**与**单次直出**两种生成模式。

> 节拍驱动 · 编舞主导 · 多角色流水线 · 实测验证（MiniMax H3 本地 15s/6s 成片）

## 先选控制权：全托管、辅助、还是全手动？

**全流程有 10 个可控维度**（执行模式、生成模式、音乐窗口、舞种、能量等级、镜头数、
分镜序列、特写清单、转场、负面词）。你可以整体选档位，也可以只对某几项表态：

| 档位 | 怎么说 | 你要给什么 |
|---|---|---|
| **Auto 全托管** | 「你看着办」「全部自动」 | 只给**角色素材 + 音乐**，其余系统决定并附推荐理由 |
| **Assisted 辅助**（默认） | （不特别说明时） | 系统只问 4 项：执行模式 / 生成模式 / 舞种 / 镜头数 |
| **Manual 全手动** | 「每一项都问我」「我自己定」 | 逐项确认，但每项都带默认值供参照 |
| **混合** | 「舞种我自己选，其他你定」 | 指定哪几项手动，其余走自动 |

**无论哪个档位，系统自动给出的每一项都会附一句话推荐理由**——
让你知道为什么这么选、想改该改哪一项。

| 维度 | 自动默认 | 维度 | 自动默认 |
|---|---|---|---|
| C1 执行模式 | 提示词模式 | C6 镜头数 | 网格枚举后取中位 |
| C2 生成模式 | 四视图→逐镜；1 张图→直出 | C7 分镜序列 | 按角度纪律自动排 |
| C3 音乐窗口 | drop − 7s 起 | C8 特写清单 | 宪法 5 处 |
| C4 舞种 | 按卡点密度 + drop 推荐 | C9 转场 | 动作遮罩优先 |
| C5 能量等级 | 按卡点密度定 L1–L5 | C10 负面词 | 两层集 |

> 手动项与硬约束冲突时，一律按「**冲突 / 处理 / 替代**」三件事明确告知，
> 不静默改你的要求，也不硬违宪。

## 再选模式：你想要提示词，还是要成片？

Skill 有两个正交的模式开关，一句话就能切换：

### ⓪ 执行模式：谁去生成

| | **P 提示词模式**（默认） | **R 代跑模式** |
|---|---|---|
| 说什么 | 「出提示词」「给我提示词」「我自己去生成」 | 「帮我跑」「直接生成」「出成片」「跑一条」 |
| 交付 | 卡点表 + 分镜表 + 提示词 + 负面词 + 六查 + 发布检查单 | 上面全部 **+ 成片 mp4 + 抽帧 QA** |
| 要装什么 | **什么都不用装** | ComfyUI + H3 + 依赖 + 显存预算 |

**90% 的场景是 P 模式**——零依赖，本技能的绝大部分价值（节拍、编舞、分镜、提示词、质检）
在这一步就完整交付了，后面所有脚本、ComfyUI、显存预算都跟你无关。

### ① 生成模式：内容怎么组织

| | **逐镜拼接**（默认） | **单次直出** |
|---|---|---|
| 说什么 | 「分镜」「多镜头」「6 镜」 | 「直出」「一次生成」「不切割」 |
| 做法 | 切 5–7 镜逐镜生成，装配时 trim 回节拍切点 | 一条提示词一次生成完整时长，不切割不装配 |
| 适用 | 素材齐（尤其有四视图）、要特写覆盖与镜头语言 | 只有 1 张图、模型单次时长够、要省事或先打样 |

四种组合都可以：**P+逐镜**（最常用）、P+直出、R+逐镜、R+直出。

## 这是什么

一个用于短视频舞蹈编排的 Skill（WorkBuddy 自定义技能）。与单镜头壁纸提示词的本质区别：它是**节拍驱动 + 编舞主导**的多角色流水线 ——

1. **R1 节奏分析师** 从音乐实测出毫秒级卡点表（BPM / 段落 / downbeat）
2. **R2 风格考据员** 定舞种 + 能量等级 + 场景服装
3. **R3 编舞师** 按 8 拍舞句编排，埋入 5 处可特写锚点（眼 / 嘴 / 胸 / 大腿 / 小腿）
4. **R4 镜头导演** 把锚点落进镜头 2–6，所有切点吸附节拍网格
5. **R5 提示词工程师** 按目标模型模板出稿
6. **R6 质检员** 六查放行
7. **R7 版本管理员** 归档回流 + 高危模式自动降权

## 核心能力

- **节拍精确**：`beat_tracker.py`（numpy 零依赖）实测 BPM 误差 ≤0.21%、拍对齐 2.8ms
- **切点吸附**：所有镜头边界落在实测节拍网格（±80ms），bar 优先、拍兜底
- **双生成模式**：逐镜拼接（分镜级控制）／单次直出（一条提示词出整条 15s，不切割）
- **角色四视图**：`split_char_sheet.py` 自动切格 + 生成 9:16 构图锚点，支撑多角度与特写镜头
- **特写宪法**：15s 完整版覆盖 5 处身体特写；6s 精简版降级保 3 处
- **多模型模板**：MiniMax H3 / 可灵 Kling（MC 动作迁移）/ Seedance / Vidu / 代码渲染
- **实测闭环**：4 个案例已在本地 H3 无头实跑成片，沉淀了 19 条高危降权规则（DG-001～019）

## 支持的生成路线

| 路线 | 适用 | 模型 |
|---|---|---|
| A 文本驱动 | 无特定编舞，只要角色跳舞 | H3 / Seedance 2.5 / Vidu Q4 / 可灵 4.0 |
| B 动作迁移 | 复刻某支热门舞蹈 / 有动作参考视频 | 可灵 Motion Control / H3 参考视频 / Vidu |
| C 首尾帧锁定 | 首帧起手 + 尾帧收姿已定（循环壁纸） | H3 FL2VA |

### 前置输入（缺项先补）

| 项 | 必需 | 说明 |
|---|---|---|
| **⓪ 执行模式** | ✅ | **提示词模式**（默认）或**代跑模式**。说「帮我跑 / 出成片」选后者；不说默认前者 |
| **① 生成模式** | ✅ | 逐镜拼接（默认）或单次直出。说「直出 / 一次生成 / 不切割」即选后者 |
| 角色素材 | ✅ | **优先四视图**（front 全身正面 / bust 半身 / side 纯侧 / back 背面，横向排列一张图）；没有则单张角色图（竖构图 9:16、全身或大腿以上、≥512px、背景干净）。**有背身/转身镜头必须有 back 视图** |
| 音乐或 BPM | ✅ | 有音频文件最佳（实测毫秒级卡点）；只给 BPM 会标注「假设值」，**代跑模式必须有音频** |
| 目标平台 | ✅ | 抖音 / 小红书 / B站 |
| 目标模型 | ✅ | H3 / 可灵 / Seedance / Vidu / 代码渲染 |
| 时长 | ✅ | 15s（5 处特写）或 6s（3 处特写） |
| **⑧ 舞种偏好** | ⬜ 可选 | 「用 hip-hop」「国风一点」「不要太快的手部动作」；不说就由技能推荐 |
| **⑨ 镜头 / 分镜偏好** | ⬜ 可选 | 「我要 6 镜」「先眼特写再全身」「第 3 镜背身」「最后一镜定格」；不说就自动排 |

> 只有 1 张角色图时，本 Skill 建议走**单次直出**：逐镜模式下每镜都要靠模型脑补缺失角度，漂移与构图失败率显著上升。
> 注意这说的是①生成模式——不管你选提示词模式还是代跑模式，这条都适用。

### ⑧⑨ 自选风格与镜头（v2.3 起）

**都可以不说**——不说就按技能推荐走。说了就尽量照办，但有两处硬约束要注意：

**舞种与 BPM 冲突**：每个舞种有适配 BPM 区间（如国风 70–110）。你的音乐是 124.5BPM 却要国风，
技能会先建议换相邻舞种；你坚持的话，保留国风的静态造型（水袖、身韵）而去掉跟不上的动态语汇
（大幅摆动、圆场步），并在产出标注已降级。

**镜头数不能任意指定**：合法镜数由「总时长 + 实测 BPM + 单镜 2.0–3.5s + 切点吸附节拍」共同决定。

| 条件 | 合法镜数 |
|---|---|
| 15s @124.5 BPM | **5 或 6** |
| 15s @140 BPM | **6** |
| 15s @90 BPM | **5** |
| 6s @124.5 BPM | **2** |

所以要 8 镜（1.875s/镜）或 4 镜（3.75s/镜）是做不到的，技能会取最接近的合法解并说明原因。
**所有冲突都会明确告知「冲突 / 处理 / 替代」三件事，不静默改你的要求。**

### 用法一：提示词模式（推荐大多数用户 · 零依赖）

**P + 逐镜拼接**（最常用）：

> 「用这张角色四视图 + 这首音乐，出一个 15 秒竖屏 hip-hop 舞蹈分镜，目标模型 H3，平台抖音」

交付 6 件：**卡点表 / 分镜表 / 逐镜提示词 / 负面词两层集 / 六查结论 / 发布检查单**。

**P + 单次直出**：

> 「直出 15 秒，不要切割，用这张角色图 + 这首音乐，可灵 4.0，抖音」

交付 6 件：**卡点表 / 连续运镜脚本 / 一条整段提示词（时间锚点写死）/ 负面词两层集 / 六查结论 / 节奏点抽检表 + 发布检查单**。

拿提示词去对应平台生成即可。**提示词模式不执行生成侧核验**，交付稿会写明
「本稿未经生成验证」——这不是缺陷，而是这个模式本来就不生成。

### 用法二：代跑模式 / 本地实跑（H3 · ComfyUI 无头）

面向本机有 ComfyUI + H3 工作流的使用者。**第一步先做环境自检**，不要直接跑脚本：

```bash
cd scripts
python _env.py --check      # 体检：依赖 / ffmpeg / ComfyUI 逐项报告
python _env.py --init       # 只在缺项时跑：交互式生成 config.json（本机私有，不入库）
```

自检全绿后再按 `USER-GUIDE.md` 第 4 节的方法链跑，要点：

1. **模板**：`scripts/extract_h3_snapshot.py` 从一次真实 H3 执行的输出 mp4 提取 API 快照
2. **运行**：`scripts/run_oneshot.py`（直出）或 `run_case01.py`（逐镜）同构改写
3. **音频接线**：LoadAudio → `drive_audio`/`final_audio` + `audio_mode=lock_source`
4. **景别锚点**：逐镜模式先产构图锚点图（`make_anchor.py` / `split_char_sheet.py`），喂 `first_frame`
5. **装配**：`scripts/assemble_case1025.py` 同构（trim 回切点 + 1080×1920 + 原曲混音）

> 所有本机路径（ComfyUI 根目录、ffmpeg、Python 依赖目录）都**不写死在代码里**，
> 由 `scripts/_env.py` 按「config.json → 环境变量 → 自动探测」三级定位。
> 你机器上没有 ComfyUI 也能用——只影响用法三，不影响用法一/二。

**最省事的安装方式：让 AI 帮你装。**

把整个技能包丢给你的 AI（Codex / Claude Code / WorkBuddy / Cursor 等），说一句：

## 角色四视图处理（v2.0 新增）

给一张横向排列的设定图，自动切格 + 生成 9:16 构图锚点：

```bash
cd scripts
python split_char_sheet.py --src 角色图.png --map bust,front,side,back --detect   # 先看检测结果
python split_char_sheet.py --split            # 切格（各格脚底对齐、比例一致）
python split_char_sheet.py --anchors          # 粗锚点：全身 / 上半身 / 下半身
python split_char_sheet.py --probe --from bust # 纵向刻度图 → 视觉读数
python split_char_sheet.py --tune eye --from bust --box 0.00,0.52,0.15,0.85      # 定稿特写锚点
python split_char_sheet.py --sync             # 复制到 ComfyUI input/
```

眼 / 嘴 / 胸 / 大腿 / 小腿的精确比例**必须走 `--probe` 读数后 `--tune` 定稿**，脚本不会自动猜。
完整规范与退化路径（视图不全时怎么办）见 `references/character-sheet.md`。

## 注意事项

- **发布合规**：产出随附「AI 生成」标识提醒 + 音乐授权检查（《人工智能生成合成内容标识办法》）

- **诚实标注**：无音频只给 BPM 时，产出标注「节拍为假设值」，15s 成片禁直接用假设节拍
