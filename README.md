# 短视频舞蹈编排 Short-Dance-Choreo

把「角色图 + 音乐」变成符合短视频平台节奏的 **9:16 多镜头舞蹈分镜提示词**，支持文本驱动 / 动作迁移 / 首尾帧锁定三条生成路线。

> 节拍驱动 · 编舞主导 · 多角色流水线 · 实测验证（MiniMax H3 本地 15s/6s 成片）

---

## 这是什么

一个用于短视频舞蹈编排的 Skill（WorkBuddy 自定义技能）。与单镜头壁纸提示词的本质区别：它是**节拍驱动 + 编舞主导**的多角色流水线 ——

1. **R1 节奏分析师** 从音乐实测出毫秒级卡点表（BPM / 段落 / downbeat）
2. **R2 风格考据员** 定舞种 + 能量等级 + 场景服装
3. **R3 编舞师** 按 8 拍舞句编排，埋入 5 处可特写锚点（眼 / 嘴 / 胸 / 大腿 / 小腿）
4. **R4 镜头导演** 把锚点落进镜头 2–6，所有切点吸附节拍网格
5. **R5 提示词工程师** 按目标模型模板出稿
6. **R6 质检员** 六查放行
7. **R7 版本管理员** 归档回流 + 高危模式自动降权

## 核心能力

- **节拍精确**：`beat_tracker.py`（numpy 零依赖）实测 BPM 误差 ≤0.21%、拍对齐 2.8ms
- **切点吸附**：所有镜头边界落在实测节拍网格（±80ms），bar 优先、拍兜底
- **特写宪法**：15s 完整版覆盖 5 处身体特写；6s 精简版降级保 3 处
- **多模型模板**：MiniMax H3 / 可灵 Kling（MC 动作迁移）/ Seedance / Vidu / 代码渲染
- **实测闭环**：3 个案例已在本地 H3 无头实跑成片，沉淀了 18 条高危降权规则（DG-001～018）

## 支持的生成路线

| 路线 | 适用 | 模型 |
|---|---|---|
| A 文本驱动 | 无特定编舞，只要角色跳舞 | H3 / Seedance 2.5 / Vidu Q4 / 可灵 4.0 |
| B 动作迁移 | 复刻某支热门舞蹈 / 有动作参考视频 | 可灵 Motion Control / H3 参考视频 / Vidu |
| C 首尾帧锁定 | 首帧起手 + 尾帧收姿已定（循环壁纸） | H3 FL2VA |

## 快速开始

### 前置输入（缺项先补）

| 项 | 必需 | 说明 |
|---|---|---|
| 角色图 | ✅ | 竖构图 9:16、全身或大腿以上、≥512px、背景干净；有背身/转身镜头须补背面图 |
| 音乐或 BPM | ✅ | 有音频文件最佳（实测毫秒级卡点）；只给 BPM 会标注「假设值」 |
| 目标平台 | ✅ | 抖音 / 小红书 / B站 |
| 目标模型 | ✅ | H3 / 可灵 / Seedance / Vidu / 代码渲染 |
| 时长 | ✅ | 15s（5 处特写）或 6s（3 处特写） |

### 用法一：只出提示词（推荐大多数用户）

给 Skill 一句话指令，例如：

> 「用这张角色图 + 这首音乐，出一个 15 秒竖屏 hip-hop 舞蹈分镜，目标模型 H3，平台抖音」

Skill 会交付固定 6 件：**卡点表 / 分镜表 / 逐镜提示词 / 负面词两层集 / 六查结论 / 发布检查单**，拿提示词去对应平台生成即可。

### 用法二：本地实跑（H3 · ComfyUI 无头）

面向本机有 ComfyUI + H3 工作流的使用者，完整方法见 `USER-GUIDE.md` 第 4 节，要点：

1. **模板**：`scripts/extract_h3_snapshot.py` 从一次真实 H3 执行的输出 mp4 提取 API 快照
2. **运行**：`scripts/run_case01.py` 同构改写（逐镜提交 + 轮询 + 落盘，~2.5min/镜）
3. **音频接线**：LoadAudio → `drive_audio`/`final_audio` + `audio_mode=lock_source`
4. **景别锚点**：特写/中景镜先生产构图锚点图（`make_anchor.py`），切 Hybrid 路线喂 `first_frame`，帧 0 景别会精确命中
5. **装配**：`scripts/assemble_case01.py` 同构（trim 回切点 + 1080×1920 + 原曲混音）

### 最快起跑

复制 `cases/case-01-15s-otaku-h3.md` 的结构，替换角色图与音乐窗口，其余照抄。

## 依赖

- **纯提示词用法**：无依赖
- **本地节拍分析**：Python 3 + numpy + ffmpeg（`beat_tracker.py` 零第三方依赖）
- **本地 H3 实跑**：ComfyUI + MiniMax H3 工作流 + Qwen-Image-Edit（可选，用于锚点图）

## 注意事项

- **发布合规**：产出随附「AI 生成」标识提醒 + 音乐授权检查（《人工智能生成合成内容标识办法》）
- **内容尺度**：默认克制、可公开发布；拒绝真人换脸/深度合成特定真人
- **诚实标注**：无音频只给 BPM 时，产出标注「节拍为假设值」，15s 成片禁直接用假设节拍
