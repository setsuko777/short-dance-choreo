## 使用规则

1. 按 R2 定档（舞种 + 能量 + BPM）选条目；BPM 不符时按条目头标注的拍周期换算，**不改变拍的序列**
2. 条目是 8 拍单元；15s 成片 = 多舞句拼接，拼接处优先落在 downbeat
3. 每条必带「可特写化」标注；QA 查 1 按「R3 动作侧 + R4 镜头侧」双侧核对
4. 复用率控制：同条目在 M4 测试集中 ≤3 次；整段照抄不改编排 = 高危，R7 降权
5. **降权闭环**：同废片原因 ≥3 例 → 标「高危」→ 本表下方降权记录登记，复用需 QA 特批
