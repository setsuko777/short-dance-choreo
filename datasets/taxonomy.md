# 六维标签体系（Taxonomy）

> 版本：v1.0（2026-10-24）· 每条入库样本必须带全六维标签，缺一不收

| 维度 | 取值 | 说明 |
|---|---|---|
| **D1 舞种/风格** | K-pop · Hip-hop（Middle/LA-style）· 宅舞/二次元 · 国风 · Jazz/urban choreography · Breaking（仅 toprock）· 社交潮流舞 · Latin · 慢板律动(R&B) | 种子来自 AIST++ 十舞种（Break/Pop/Lock/Waack/Middle Hip-hop/LA-style/House/Krump/Street Jazz/Ballet Jazz）+ 二次元/国风两个增量类；AIST++ 全集与本地取值域的映射见 `sources.md` #1 |
| **D2 能量等级** | L1 慢板律动 / L2 中速 / L3 中快 / L4 高速卡点 / L5 drop 爆发 | 决定动作密度与镜头切分节奏；定档规则见 `../references/style-library.md` |
| **D3 BPM 区间** | <80 · 80–100 · 100–120 · 120–140 · >140 | 与 D2 交叉验证；矛盾时以实测为准并记录 |
| **D4 镜头语言** | 定点 / 缓慢推近 / 缓慢横移 / 手持微晃 / 低角度仰拍（计入俯仰次数）；环绕 = 高危变体（drop 段特批） | 与 R4 机位库一一对应（`../references/camera-language.md`） |
| **D5 景别与特写锚点** | 全身 / 中景 / 近景 / 特写（眼·嘴·胸·大腿·小腿） | 特写五件套是硬性字段；6s 精简版标「降级」 |
| **D6 场景×服装** | 舞台打光 / 街头夜景 / 室内自然光 / 纯色影棚 / 国风场景；服装 = 垂坠感裙装 / 宽松街装 / 舞台服 / 国风服 | 服装影响崩坏率（垂坠感 > 硬挺） |

## 质量门槛（准入标准）

一条样本进入 `datasets/` 必须同时满足：

1. 六维标签齐全（D1–D6）
2. 动作分解到 8 拍单元，且每拍有可特写化标注 + 通过条件
3. 带卡点时间轴（毫秒级或至少拍级）+ 吸附锚点标注
4. 来源可追溯（链接/自产记录/授权记录）
5. 通过去重检查（同舞种 + BPM + 动作序列指纹去重）
