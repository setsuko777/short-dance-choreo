# 高危降权记录总账（R7 模式级）

> 版本：v1.0（2026-10-24，M3 开跑）· 责任人：R7 版本管理员 · 与 `l3-moves/README.md` 的舞句级降权表分工：
> **本表管「模式」**（一类动作/一种做法全局降权，一条记录管所有条目）；**舞句级表管「个体」**（某条舞句/某个镜头模式因具体废片被降权，需案例数据触发）。

## 字段定义

| 字段 | 含义 |
|---|---|
| 编号 | DG-XXX，按登记顺序 |
| 高危模式 | 一句话描述被降权的做法 |
| 等级 | **禁用**（默认不用）/ **降级**（换成保守替代）/ **观察**（可用但须标注） |
| 触发条件 | 什么情况下命中（输入特征 / 检出信号） |
| 降权动作 | 命中后强制换成什么 |
| 恢复条件 | 满足什么才能解除（无「默认恢复」，必须显式条件） |
| 证据来源 | 规则出处（宪法 / 数据集设计 / M0-M3 实测 / 外部实证） |
| 案例数 | 数据驱动的废片累计（M4 起累计；预防性规则不依赖案例） |
| 状态 | 生效 / 观察中 / 已解除（附日期） |

## 数据驱动降权（M4 起开跑）

以下两类由案例数据触发，当前案例数 = 0（cases/ 空库），**如实留空**：

- **舞句级**：同废片原因 ≥3 例的舞句 → `l3-moves/README.md` 降权记录表登记（当前：暂无）
- **模式级**：某模式废片率 >50%（同模式 ≥4 例中 ≥2 废）→ 升「禁用」并回写本表 + move-library 下架

## 纪律

1. 新增降权必须带**证据来源**；无出处的猜测不进表（防拍脑袋规则）
2. 「恢复条件」必须是可验证的显式条件，禁止「默认恢复」
3. 状态改「已解除」必须记日期 + 解除人 + 验证证据
4. 每季度（或矩阵月度复核时）过一遍本表：案例数 = 0 的观察项评估是否转正或下架
