# L3 授权动作片段采集规范（Motion Sources）

> 版本：v1.0（2026-10-24）· 目标 20 段授权动作片段 · **当前状态：0 段已采集（台账为空表，待人工采集）**

## 用途

路线 B（动作迁移）的参考视频池：可灵 Motion Control 用「1 角色图 + 1 动作视频」逐帧复刻编舞，是「复刻平台热门舞蹈」保真度最高的路线。片段质量直接决定路线 B 上限。

## 输入规范（可灵 MC 硬性要求，不符即不可用）

| 项 | 要求 |
|---|---|
| 时长 | 3–30s（Match Video） |
| 主体 | **单人**、全程无切镜、无运镜 |
| 分辨率 | 短边 ≥340px、长边 ≤3850px |
| 内容 | 动作清晰、无遮挡、舞者全身入画 |
| 音频 | 保留原声（MC 不生成新音频） |

## 采集 SOP

1. **选段**：按覆盖矩阵选目标片段；确认单人/无切/无运镜/时长合规
2. **授权确认**：自拍或取得书面/平台授权；**无授权不录入**（宁可留空）
3. **登记**：填上表（片段ID 规则：`MS-序号-舞种`，如 `MS-01-kpop`）
4. **标注**：跑 R1 节拍分析 → 按 annotation-spec 拆 8 拍舞句 → 六维标签
5. **入池**：片段入 `examples/input/` 同级素材目录（或用户指定位置）；拆解条目追加进 `l3-moves/` 对应舞种文件，标「L3-授权片段派生」
6. **M4 验证**：每段至少跑 1 次路线 B 端到端，结果回流 `cases/`

## 版权红线（重申）

- 不整段爬取受版权保护的编舞视频作参考片段
- 未授权片段只做动作元素级拆解（文字标注），不进参考视频池
- 授权记录必须真实可查；本台账任何一行都不得虚构
