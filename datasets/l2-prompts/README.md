## 使用方式

1. 按 R2 定档结论（舞种 + 能量 + 平台）选文件
2. 在文件内按「特写锚点 + 场景 + 机位」三筛选定位候选条目
3. 条目提示词为**单镜**粒度；多镜成片按 Phase 4 分镜表逐镜取用/改写，不得整段照抄（照抄 = 高危，R7 降权）
4. 改写后必须重跑 R6 六查（特写双侧锚点、切点吸附、负面词集）
