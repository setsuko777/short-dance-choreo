# 样例输入 #01 — 15s 完整版（路线 A / MiniMax H3 / 抖音）

> 本样例为 M1 手写稿：动作库（M3）尚未建成，用于验证输出格式与规则闭环。实际执行时应对真实音频先跑 `scripts/beat_tracker.py` 获取实测卡点表；本样例的 96BPM 为**假设值**。

## 输入参数

| 项 | 值 |
|---|---|
| 角色图 | 设定图一套（正面 + 侧面 + **背面图**齐备），9:16 全身站姿，≥512px，主体 ≥60%，背景干净 |
| 首帧图 | 有（起手姿态 + 背景：室内自然光暖色调） |
| 尾帧图 | 无（末镜定格 = 首帧起手姿态，循环拼接） |
| 音乐 | 用户只给感觉词「燃」→ 假设 96BPM 中快 K-pop（假设值，产出已标注） |
| 平台 | 抖音（卡点优先，drop 前置） |
| 目标模型 | MiniMax H3（Ref2VA） |
| 时长 | 15s 完整版（6 镜） |
| 必选特写 | 眼 / 嘴 / 胸 / 大腿 / 小腿（全五件套） |
| 生成路线 | A 文本驱动（无特定编舞，只要角色跳舞） |
| 风格偏好 | K-pop · L3 中快 · 舞台服 |
